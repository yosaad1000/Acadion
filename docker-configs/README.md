# Docker Configurations

Docker-related configuration files for containerized deployment.

## Docker Compose Files
- `docker-compose.yml` - Main docker compose configuration
- `docker-compose.prod.yml` - Production configuration
- `docker-compose.backend-only.yml` - Backend only
- `docker-compose.https.yml` - HTTPS configuration
- `docker-compose.nginx.yml` - Nginx configuration
- `docker-compose.microservices.yml` - Microservices setup
- And more...

## Dockerfiles
- `Dockerfile` - Main Dockerfile
- `Dockerfile.backend` - Backend Dockerfile
- `Dockerfile.frontend` - Frontend Dockerfile
- `Dockerfile.backend.https` - Backend with HTTPS

## Other
- `.dockerignore` - Docker ignore file
