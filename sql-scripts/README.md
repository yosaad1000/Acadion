# SQL Scripts

Database-related SQL scripts for Supabase configuration and fixes.

## RLS (Row Level Security) Fixes
- `SIMPLE-ONE-LINE-FIX.sql` - Quick fix to disable RLS
- `FINAL-FIX-RLS.sql` - Complete RLS policy setup
- `allow-anon-org-creation.sql` - Allow anonymous organization creation
- `fix-rls-visibility.sql` - Fix visibility issues
- `check-and-fix-rls.sql` - Check and fix RLS policies

## Diagnostic Scripts
- `diagnose-auth-and-rls.sql` - Diagnose authentication and RLS issues
- `diagnose-organization-issue.sql` - Diagnose organization table issues
- `verify-rls-fix.sql` - Verify RLS fixes
- `view-organizations-simple.sql` - View all organizations

## Test Scripts
- `test-organization-insert.sql` - Test organization insertion
